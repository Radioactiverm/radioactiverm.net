# radioactiverm.net

Personal portfolio and homelab hub built with Google's Material Design 3 Expressive system in an interactive bento-grid layout.

## Tech Stack
- HTML5 & Vanilla CSS (Material 3 Expressive tokens & springs)
- Vanilla JavaScript & Vite
- Music Metadata parser
- Lanyard & GitHub APIs

## Getting Started
```bash
npm install
npm run dev
npm run build
npm run preview
```
